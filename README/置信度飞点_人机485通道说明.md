# 置信度/飞点 人机485通道说明（月影Pro 10寸 竖屏 标准工程配套）

> 2026.11.13 新增 | ARM侧代码：`Modbus485_Master/modbus485.c` + `Kesai_Process/ks_conf_err.*` + `Kesai_Process/ks_fly_remove.*`
> 参考来源：老架构 `Slave_stm32_ARM/Kesai_Visu/KS_FB_VISU.c` 的 46059.02/.03/.04 / 6060 / 6207 挂点，
> 接口变量与老架构一一对应，寄存器按月影Pro的区引擎落位。

## 一、通道清单（与老架构对照）

| 老架构 | 月影Pro 落位 | 变量 | 说明 |
|---|---|---|---|
| 46059.02 | 读写 3177 第13位 | `xFlyRemoveEn_485` | 飞点独立开关：1=新Theil-Sen剔除（默认）\|0=回退旧二阶差分，翻转由ARM内部自动复位剔除器 |
| 46059.03 | 读写 3177 第14位 | `xConfErrEn_485` | 置信度观察开关：1=计算并显示置信度\|0=完全原行为（显示值送0） |
| 46059.04 | 读写 3177 第15位 | `xSwitchWrEn_485` | 接入开关：仅bit14=1时有效，再=1融合误差才替换上报误差链 |
| 4WUB6060 | 读写 3178 | `wConfS50` | s50输入，单位0.001mm（80=0.08mm默认），有效范围1~1000，越界ARM保持原值，bit14=1才生效 |
| 4WUB6207 | 只写 131（现名 aRsv_HignComm_2_010） | `wConfPack` | 高8位=纵向融合置信度F(0~100)\|低8位=横向F，屏脚本自行拆字节：V=wConfPack/256，H=wConfPack%256 |

> ⚠️ 读写 3177 的 bit0~3、bit8~12 已被版辊锁/网辊锁/充气/墨盒上升/墨运行/点动/压合/松开占用，不要动。
> ⚠️ 只写区 122~130 已被 `iTorque_*`/`iVel_*`（扭矩显示）占用，不要动。
> 开关默认**全关（0/0/0）**=上电原行为（旧二阶差分飞点+无置信度），ARM 上电整区写入的也是 0，
> 屏显与实际状态天然一致，人机侧开关初值设 0 即可；需要时在人机上打开（s50 输入需 bit14=1 才生效）。

## 二、刷新特性

- 只写 131 属只写快速区（第27区，常开）：ARM 侧该字变化即随整区 0x10 发送；置信度每圈刷新。
- 读写 3177/3178 属读写区（第0区）：ARM 持续 0x03 轮询读回，屏上改开关/s50 下一轮通讯即生效。

## 四、验收要点

1. 上电开关全关=升级前原行为（旧二阶差分飞点+无置信度），屏显示与 ARM 状态一致。
2. 开 bit13：飞点判定切到新 Theil-Sen 剔除（byStsV/H bit2 语义不变）。
3. 开 bit14：wConfPack 开始送实际置信度；再开 bit15：上报误差替换为融合值。
4. wConfS50 输入 1~1000 外的值 ARM 不接受（保持原 s50=0.08mm）。
