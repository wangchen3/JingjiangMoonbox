## 4. 算法要点速览（详见配套文档）

**新飞点剔除**（与仿真 py 逐帧等价，含 2026.11.09 对齐的 qdq 口径/丢失复位/NoteDv 接线）：
- 外门槛 `T_out = max(K·σ, β·q, γ_v·|近5拍最大Δv|)`，K=5、β=10、γ_v=25
- 可信历史（只收真实测量）Theil-Sen 趋势带；飞点/暂缓替换=趋势外推 P 并刷锁存
- 首帧对一致性检查：前 2 帧差 ≤100 丝才配对采信；暂存/丢弃帧差分**不入**分辨率窗（qdq 窗只收确认喂入帧，防狂跳启动抬高门槛）
- 连续丢失 ≥4 拍自动全复位；逐帧判定码 KS_FLY_JUDGE_FIRST/GOOD/QUAR/FAKE/HOLD/STEP/LOST/TREND 写 `o_byFlyFlag_V/H`

**双置信度**（每圈一次，读 KS_CalcError_ARC 的 detail 结构，calcerr.c 零改动）：
- `C = 2^-(s_mm/s50)²`：三档交点跨圈位移一致性（两标记取短板）
- `Qn = 100·erf(τ/(√2·jp))`：门内空白区（排除区半宽=0.5×W25，2026.11.19 起半标宽——原 W25 的 3×W25 排除区在窄门工况饿死噪声窗致 Qn 显 0）分块去趋势+MAD 估 σ → 交点抖动预测 jp（τ 默认 5 丝、2026.11.17 起经 485 可调：`rConfTauSilk`/wConfTau@3180，1~100；幅值<3000 LSB 时 Qn 满分；MAD/σ 下限=1 个量化码）
- `F = √(C×Qn/100)`，递推混合 `out_k = F·E_k + (1-F)·out_{k-1}`（E_k=当圈 o_iVResult/o_iHResult；丢失圈直通 -32768；排列/色序/双波门变化自动复位 CK 历史）
- **修正量前馈直通（2026.11.18 记忆平移）**：E_k 含"已减 i_iAdjustV"口径，修正量阶跃原本会被 IIR 平滑拖慢机器反应（客户实测）；现每圈检测 ΔA 并同步平移混合记忆——数学恒等于"先 IIR 后减修正量"，修正当圈瞬时穿透，数值已验证与理想重排逐圈一致，仅改 ks_conf_err.c

## 6. 运行期行为矩阵

| bit13 飞点 | bit14 观察 | bit15 接入 | 行为 |
|---|---|---|---|
| 0（默认） | 0 | 0 | 完全原行为（旧二阶差分，无置信度）——升级前后无差别 |
| 1 | 0 | 0 | 新飞点剔除；置信度不计算 |
| 1 | 1 | 0 | 新飞点 + 置信度仅显示（A/B 观察态，误差链仍用原值） |
| 1 | 1 | 1 | 完全体：融合误差替换上报（主站/报警/人机显示平均同步跟随） |

（bit14=0 时 bit15 无效；飞点与置信度两开关互不耦合，可独立切换。）

## 8. 与权威/老架构的对应关系

- 飞点算法以 `飞点剔除仿真.py` 为权威：8.4 已含 2026.11.09 全部对齐项（qdq 启动口径、连续丢失复位、NoteDv 首拍守卫）。**老架构侧仍是 160000 半修版（qdq 半修 + NoteDv 无首拍守卫），如需对齐以 8.4 为准反向同步**（2026.11.13 评估结论，暂不修）。
- 置信度自老架构 2026.11.12 版逐行移植（含噪声窗对称、量化下限治本、快速选择），开关语义与老架构 2026.11.12 解耦版一致（bit14 只显示 / bit14&15 双开接入）。
- 老架构 ↔ 月影Pro 寄存器对照：46059.02/.03/.04 → 读写 3177 bit13/14/15；4WUB6060 → 4WUB3178；4WUB6207 → 读写 4WUB3179（2026.11.16 起由只写 131 挪入）。

## 9. 验收清单

1. 烧录后上电（三开关全关）：行为与旧版固件一致，屏上开关显示 0。
2. 开 bit13：误差队列/人机显示切新飞点特性；byStsV/H bit2（飞点标志）语义不变。
3. 开 bit14：读写 3179 开始出现实际置信度（V/H 各 0~100）；再开 bit15：上报误差变为融合值（与 o_iVResult 相比按 F 平滑）。
4. wConfS50 输 0 或 >1000、wConfTau 输 0 或 >100：ARM 均不接受（分别保持 0.08mm / 5 丝），输 80/5 与默认等价。
5. 开关翻转（任意沿）：飞点剔除器自动复位重新暖机（首次输出为首帧对采信值）。
6. 断电重启：开关回到 0/0/0（人机主权重写），行为回原。
